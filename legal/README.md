# Legal pages — TEMPLATES, NOT LEGAL ADVICE

These are starting drafts. Every `[BRACKETED]` field must be filled in, and the
result should be reviewed by someone qualified in your jurisdiction before you
take a single real payment. Consumer law, distance-selling rules and data
protection differ by country, and getting them wrong is expensive.

Fill in once, in all three files:

| Placeholder | What goes there |
|---|---|
| `[LEGAL BUSINESS NAME]` | Registered company or sole-trader name |
| `[TRADING NAME]` | The name customers see, if different |
| `[COMPANY NUMBER]` | Companies House / equivalent registration number |
| `[VAT NUMBER]` | If registered |
| `[REGISTERED ADDRESS]` | Full postal address |
| `[SUPPORT EMAIL]` | A monitored address |
| `[SUPPORT PHONE]` | Optional but builds trust |
| `[COUNTRY]` / `[JURISDICTION]` | Governing law |
| `[RETURN WINDOW]` | e.g. 14 days (UK/EU statutory minimum for distance sales) |
| `[RETURN ADDRESS]` | Where goods come back to |

Serve them as real pages and link them from the footer and the checkout.
